PHP Native Conflict Detection SKS Load Balancing Minara College Case

The Challenge

Case Study: Minara College. Managing class schedules by hand often leads to conflicts (a lecturer booked in two places at once, or a room used twice) and uneven teaching loads (credit hours) between lecturers.

The college needed a system that validates the possible combinations of lecturer, course, room, and time in real time, right before the data is saved.

Technical Solution

I built the system in plain native PHP to keep the heavy query logic fast without framework overhead.

  • Double-Constraint Check: Checks both room and time conflicts and lecturer and time conflicts.
  • Credit Load Monitoring: Automatic calculation that prevents overloading a lecturer's teaching credit hours.
  • Print Friendly: Class schedules can be printed straight to PDF.

Relational Logic Architecture

The core of the system is the ploting_mengajar (teaching assignment) table, which acts as a bridge table connecting the other entities.

  • pengampu (course lecturer): links lecturer, course, class, and academic year.
  • jadwal (schedule): stores available day, time, and room slots.
  • ploting_mengajar: joins a course lecturer to a schedule slot after validation.

Conflict Validation Logic:

IF (Room = 'Lab Kom 1' AND Time = '08:00-10:00') EXISTS
OR

=> REJECT INPUT (CONFLICT)
ELSE
=> SAVE DATA to ploting_mengajar
ConflictCheck.php (The Anti-Conflict Algorithm)

This is the native PHP code I used to check for time overlap, so no schedule clashes on either the room or the lecturer.

function cekBentrok($hari, $jam_mulai, $jam_selesai, $id_ruang, $id_dosen) {
    global $koneksi;

    // 1. Room conflict check (is the room already in use?)
    $queryRuang = "SELECT * FROM jadwal 
                   JOIN ploting_mengajar ON jadwal.id_jadwal = ploting_mengajar.id_jadwal
                   WHERE hari = '$hari' 
                   AND id_ruang = '$id_ruang'
                   AND (
                       ('$jam_mulai' >= jam_mulai AND '$jam_mulai' < jam_selesai) OR
                       ('$jam_selesai' > jam_mulai AND '$jam_selesai' <= jam_selesai)
                   )";

    $cek1 = mysqli_num_rows(mysqli_query($koneksi, $queryRuang));
    
    // Any match (cek1 > 0) means the times overlap
    if ($cek1 > 0) return "Error: The room is already in use at that time!";

}
