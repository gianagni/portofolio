# Security Policy

Thanks for helping keep this project safe.

## Scope

This repository contains the source for a public, static personal portfolio. It is **not** the source repository for the products featured in the portfolio.

## Reporting a vulnerability

**Please do not report exploitable security vulnerabilities through public GitHub issues or discussions.**

Email **nanditogianza@gmail.com** with the subject:

`[SECURITY] Portfolio vulnerability report`

Please include:

- A short summary and the affected page or file.
- Steps to reproduce, with a minimal proof of concept if possible.
- The potential impact and any relevant browser details.
- Whether the issue could expose user information or credentials.

Do not include real credentials, personal data, or information obtained from other users. Please avoid testing that could degrade the live site or third-party services.

Reports will be reviewed when possible. No fixed response or resolution time is promised. Please allow time for review before publishing vulnerability details.

## Third-party services

The website uses external services for certain functionality, including Open-Meteo. Vulnerabilities in third-party services should also be reported to their respective maintainers.
