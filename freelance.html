Project Management System

Freelance OS Dashboard.

CodeIgniter 4 MySQL Relation CRM Logic Payment Tracking

The Challenge

Problem Statement: Freelancers often struggle to track parallel projects, unpaid invoices, and deadlines because the data is scattered across Excel, WhatsApp, and email.

They need one central system that manages clients (clients), project progress (projects), and payment history (payments) in a single dashboard.

Technical Solution

I built Freelance OS with CodeIgniter 4 using MVC. The main focus was efficient queries and a fully connected data structure.

  • Relational Integrity: Foreign key constraints (ON DELETE CASCADE) keep client and project data in sync.
  • Status Workflow: Project status (Pending, On Progress, Selesai) is stored as an ENUM in the database.
  • Financial Recap: The remaining balance is calculated automatically as project value minus total payments received.

Database Relations (CRM Core)

Based on the db_freelance.sql structure, the database is designed around CRM (customer relationship management) needs.

  • clients: Master client data (name, organization, WhatsApp, email).
  • projects: Linked directly to a client ID, with key fields such as nilai_proyek (project value) and tanggal_deadline (deadline).
  • payments: Linked to a project ID. Records each installment payment (jumlah_bayar) over time.

SQL Schema Snapshot:

Table: Projects
- id (PK)
- client_id (FK -> clients.id)
- nilai_proyek (DECIMAL)
- status ENUM('Pending', 'On Progress', 'Selesai', 'Batal')
- deadline (DATE)

ProjectModel.php (Financial Health Calculation)

This is the backend logic (a CI4 model) I wrote to calculate each project's financial health in real time: total project value versus the amount already paid.

public function getProjectFinancials($projectId) {
    // 1. Load the project (CI4 model)
    $project = $this->find($projectId);
    
    // 2. Sum all payments received (Query Builder)
    $db = \Config\Database::connect();
    $totalPaid = $db->table('payments')
                    ->where('project_id', $projectId)
                    ->selectSum('jumlah_bayar')
                    ->get()->getRow()->jumlah_bayar;

    // 3. Remaining balance and payment progress (percentage)
    $remaining = $project['nilai_proyek'] - $totalPaid;
    $percentage = ($totalPaid > 0) ? ($totalPaid / $project['nilai_proyek']) * 100 : 0;

    return [
        'project_name' => $project['nama_project'],
        'contract_value' => $project['nilai_proyek'],
        'paid_amount' => $totalPaid,
        'remaining_balance' => $remaining,
        'payment_status' => ($remaining <= 0) ? 'PAID OFF' : 'UNPAID'
    ];
}
