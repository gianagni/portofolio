Gianagni Audio Bot.

Node.js Discord.js v14 FFmpeg Media Stream End-to-End Encryption

The Challenge

Building a Discord music bot used to be simple, until Discord rolled out the DAVE Protocol (end-to-end encryption) for voice channels. Bots without support for the protocol can no longer send audio and go silent.

The challenge was updating the bot's voice layer so it can complete the DAVE encryption handshake with Discord, while converting a Zeno FM radio stream (MP3) to Opus in real time.

Technical Solution

I reworked the bot's backend with Node.js and the latest @discordjs/voice library ecosystem.

  • DAVE E2EE support: Integrated @snazzah/davey as the DAVE protocol implementation, so the bot can join and send audio in encrypted voice channels.
  • Audio Transcoding: Uses ffmpeg-static to convert media on the fly.
  • Memory Optimization: Audio metadata is not cached, keeping memory usage stable while the bot runs 24/7.

Voice Encryption Architecture

Since DAVE was enforced, a bot must complete a valid cryptographic handshake before it is allowed to send voice packets over UDP.

Security Components (Dependencies):
1. @snazzah/davey: Starts and maintains the DAVE protocol session.
2. tweetnacl: Cryptography library used to validate key signatures locally.
3. libsodium-wrappers: Encrypts every audio packet for Discord's voice transport before it is sent.

DAVE Protocol Flow:

Bot Request Join Voice Channel
Discord Server: "Require E2EE Key!"
snazzah/davey generates Session Key
tweetnacl signs the packet
Discord Server: "Handshake Accepted"
FFmpeg opens OPUS Stream Pipeline.
index.js (Backend Logic: Audio Resource Injection)

This is the core logic for playing the radio stream. Using StreamType.Arbitrary is essential: it stops FFmpeg from trying to download the whole radio station (an endless stream) and has it pass the raw data through instead.

const connection = joinVoiceChannel({
    channelId: voiceChannel.id,
    guildId: interaction.guild.id,
    adapterCreator: interaction.guild.voiceAdapterCreator,
});

const player = createAudioPlayer();

// StreamType.Arbitrary: makes FFmpeg read the internet radio stream (Zeno FM)
// without downloading its metadata first (prevents RAM overload).
const resource = createAudioResource('http://stream.zeno.fm/f3wvbbqmdg8uv', {
    inputType: StreamType.Arbitrary,
});

player.play(resource);
connection.subscribe(player);

// Event Listener Debugging State
player.on(AudioPlayerStatus.Playing, () => {
    console.log('DAVE stream active: music is playing on Discord.');
});
