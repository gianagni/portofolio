Financial System

Cash Management System.

CodeIgniter 4 Recurring Engine Budget Controlling Multi-Wallet Logic

The Challenge

Most finance apps only record the past without giving any control over what comes next. Users often forget to log recurring monthly bills, or don't notice that their e-wallet balance differs from their actual bank balance.

Technical Solution

I implemented a recurring transaction engine that runs as a CRON job to record repeating transactions automatically (such as streaming subscriptions).

A multi-wallet system keeps balances separate per account (bank, cash, e-wallet) while still adding them up in one main dashboard.

Database Logic (Schema Analysis)

Based on the db_cashmanagement.sql schema, the data model is built to be flexible. The recurring_transactions table stores bill schedules, while transfers records money moving between wallets without counting it as real spending (a zero-sum movement).

  • Soft Deletes: An is_active flag on the recurring table keeps history intact when a user deletes a bill schedule.
  • Budget Constraints: The budgets table is related to categories to trigger warnings when spending passes a threshold (70% warning, 90% alert).

Recurring Table Structure:

TABLE recurring_transactions (
  id INT PK,
  frequency ENUM('daily', 'monthly'),
  day_of_month TINYINT,
  last_executed DATE,
  is_active TINYINT DEFAULT 1
);
TransactionController.php (Key Logic: Atomic Transfer)

Transfers between wallets use an ACID transaction to keep the data consistent. Money is never lost or duplicated if the connection drops in the middle of a balance transfer.

public function transferBalance() {
    $this->db->transStart(); // Start the ACID transaction

    try {
        // 1. Deduct from the sender
        $this->walletModel->deductBalance($fromId, $amount);

        // 2. Add to the receiver
        $this->walletModel->addBalance($toId, $amount);

        // 3. Record in transfers (not in transactions/expenses)
        $this->transferModel->save([
            'from_account_id' => $fromId,
            'to_account_id' => $toId,
            'amount' => $amount
        ]);

        $this->db->transComplete(); // Commit the changes
    } catch (\Exception $e) {
        // Auto rollback: undo every query if any single one fails
        log_message('error', 'Transfer failed: ' . $e->getMessage());
    }
}
