# Contributing

Thanks for taking an interest in this portfolio. This repository is primarily a personal website, but constructive feedback and small improvements are welcome.

## Good contributions

- Report a broken page, link, or terminal command.
- Fix typos or improve accessibility and responsive behavior.
- Suggest performance improvements that don't add unnecessary dependencies.
- Point out inaccurate project descriptions or misleading technical claims.

For major design changes or new features, please open an issue first so we can discuss the scope.

## Development workflow

1. Check existing issues and pull requests to avoid duplicates.
2. Open an issue that explains the problem, its impact, and how to reproduce it.
3. If a code change makes sense, create a branch and keep the change focused.
4. Run the existing checks before opening a pull request:

   ```bash
   node --check script.js
   node --check featured-terminal.js
   python3 scripts/check_static.py
   ```

5. Explain what changed, why it was needed, and how you tested it. Include before-and-after screenshots for visual changes.

## A few boundaries

- Keep portfolio content factual and avoid exposing private or internal company information.
- Don't add third-party assets or code without permission and proper attribution.
- Please don't open a public issue for a security vulnerability. See [SECURITY.md](SECURITY.md).
- Contributions are reviewed at the maintainer's discretion. Opening a pull request doesn't guarantee acceptance.
