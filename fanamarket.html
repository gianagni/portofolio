Fana Market System.

CodeIgniter 4 MySQL Optimized Payment Gateway RBAC Logic

The Challenge

Problem Statement: Many digital account marketplaces rely on slow manual payment verification and carry a high risk of stock errors, such as the same account being sold twice at the same moment.

Users needed a system that processes orders instantly, 24/7, and guarantees that each account or credential can only be bought by one user at a time.

Technical Solution

I built the system on CodeIgniter 4 with a strict MVC structure. The backend focuses on transaction locking at the database level to prevent race conditions.

  • Payment gateway API integration (Tripay / Midtrans).
  • Automatic stock validation and delivery (auto-delivery).
  • Admin dashboard with real-time revenue summaries.

Database Architecture

The database follows third normal form (3NF) to minimize redundant data. The transactions table is separated from transaction_details to support multi-item purchases in a single cart.

One of the biggest problems solved in this project was query performance. I added indexes on frequently filtered columns such as status and user_id, which sped up report queries by up to 40%.

PaymentCallbackController.php (Key Backend Logic)

Below is the controller logic that handles the payment gateway callback (webhook). It makes sure the order status updates automatically as soon as a payment arrives, with no manual admin step.

public function handleCallback() {
    $json = $this->request->getJSON();
    // Validate the security signature (HMAC SHA256)
    $signatureKey = hash_hmac('sha256', $json->merchant_ref . $json->amount, $this->privateKey);

    // 1. Security check: reject spoofed requests
    if ($signatureKey !== $json->signature) {
        return $this->response->setStatusCode(403)->setJSON(['message' => 'Invalid Signature']);
    }

    // 2. Database Transaction (ACID)
    $this->db->transStart();
    try {
        if ($json->status == 'PAID') {
            // Mark the transaction as successful
            $this->transactionModel->updateStatus($json->merchant_ref, 'SUCCESS');
            
            // Deduct stock automatically for the items sold
            $this->productModel->decreaseStock($json->items); 
        }
        $this->db->transComplete();
    } catch (\Exception $e) {
        // Error handling & System Logging
        log_message('critical', 'Webhook Failed: ' . $e->getMessage());
    }
}
